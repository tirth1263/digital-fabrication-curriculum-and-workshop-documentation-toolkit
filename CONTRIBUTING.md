# Contributing

Contributions are welcome when they improve clarity, safety, accessibility, or practical usefulness for digital fabrication training.

## Contribution guidelines

- Keep documents modular so facilitators can copy individual files into workshops.
- Write for mixed audiences: students, instructors, lab managers, and technicians.
- Include safety assumptions and required supervision when adding procedures.
- Prefer checklists, tables, and step sequences for workshop-facing materials.
- Avoid machine-specific claims unless the document names the machine and controller.
- Use plain Markdown so the toolkit remains easy to read on GitHub.

## Suggested contribution types

- New experiment outlines
- Improved safety checklists
- Workshop documentation examples
- Assessment rubric improvements
- Additional diagrams
- Accessibility improvements
