# Facilitator Guide

## Facilitator role

The facilitator creates the learning frame, coordinates safe access to equipment, and helps participants turn workshop activity into documented knowledge. The goal is not simply to complete a fabrication output. The goal is to help participants understand the relationship between design decisions, machine behavior, material response, and evidence-based iteration.

## Before the workshop

- Confirm instructor, technician, and participant roles.
- Verify the robot cell, emergency stop, tooling, material, and extraction requirements.
- Prepare a workshop brief using the template in `docs/templates/workshop-brief-template.md`.
- Complete a risk assessment using `docs/templates/risk-assessment-template.md`.
- Select one primary experiment and one fallback activity.
- Print or share the relevant safety checklists.
- Prepare a documentation folder for photos, parameter notes, toolpath files, and participant summaries.

## During the workshop

Use a repeated structure:

1. State the fabrication objective.
2. Name the safety boundary.
3. Demonstrate the workflow.
4. Let participants observe and annotate.
5. Run a guided attempt.
6. Pause for documentation.
7. Review what changed, what failed, and what should be tested next.

## Suggested full-day agenda

| Time | Activity |
| --- | --- |
| 09:00 | Welcome, goals, and safety orientation |
| 09:45 | Digital fabrication workflow overview |
| 10:30 | Robot motion and tooling demonstration |
| 11:15 | Guided toolpath planning activity |
| 12:00 | Break |
| 13:00 | Material experiment setup |
| 14:00 | Fabrication trials and documentation |
| 15:30 | Group review and rubric discussion |
| 16:15 | Workshop summary drafting |
| 17:00 | Closeout and cleanup |

## Documentation expectations

Every workshop should capture:

- Workshop title, date, location, facilitator, and participant count
- Machine, controller, software, material, tooling, and fixtures
- Safety checks completed before machine operation
- Design files or sketches used to generate the workflow
- Toolpath or program assumptions
- Trial variables and observations
- Failures, interruptions, near misses, or unexpected outcomes
- Photos of setup, process, and final results
- Recommended changes for the next session

## Facilitation tips

- Keep demonstrations short enough that participants still have time to test assumptions.
- Treat failed outcomes as data, but never normalize unsafe behavior.
- Ask participants to document decisions before seeing results.
- Separate design critique from machine-operation critique.
- Save enough time for cleanup and workshop summary writing.
