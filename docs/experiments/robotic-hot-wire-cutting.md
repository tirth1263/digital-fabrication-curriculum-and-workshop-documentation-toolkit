# Experiment: Robotic Hot Wire Cutting

## Aim

Evaluate how wire temperature, travel speed, and foam density affect cut quality and path accuracy.

## Suitable for

Supervised demonstrations using approved foam materials, ventilation, and hot-wire equipment.

## Variables

| Variable | Suggested levels |
| --- | --- |
| Wire temperature or power setting | Low, medium, high |
| Travel speed | Slow, baseline, fast |
| Lead-in distance | Short, medium, long |
| Foam density | Material-dependent |

## Constants

- Wire length and tension
- Tool orientation
- Fixture setup
- Path geometry
- Ventilation condition

## Procedure

1. Confirm material compatibility and ventilation.
2. Inspect wire condition and fixture clearance.
3. Run a cold dry path.
4. Heat the wire using the approved procedure.
5. Cut one simple path at baseline settings.
6. Change one variable and repeat.
7. Allow material and equipment to cool before handling.

## Observation prompts

- Did the cut lag behind the programmed path?
- Was there visible melting, smoke, or residue?
- Did the foam move in the fixture?
- Was the kerf consistent?

## Safety notes

Hot-wire cutting can generate heat, fumes, and burn hazards. Use only approved materials and ventilation, and follow local lab rules.
