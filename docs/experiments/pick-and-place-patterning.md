# Experiment: Pick and Place Patterning

## Aim

Test how object tolerance, grip force, approach motion, and release strategy affect repeatable placement.

## Suitable for

Introductory robotic assembly, tile placement, block stacking, or modular patterning exercises.

## Variables

| Variable | Suggested levels |
| --- | --- |
| Approach height | Low, medium, high |
| Grip force or vacuum level | Low, baseline, high |
| Placement speed | Slow, baseline, fast |
| Release delay | Short, baseline, long |

## Constants

- Object geometry
- Surface material
- Gripper type
- Placement pattern
- Work coordinate frame

## Procedure

1. Inspect gripper and payload limits.
2. Mark the pickup and placement zones.
3. Run the path without payload.
4. Run one pickup and place cycle at low speed.
5. Record final position error.
6. Repeat trials while changing one variable.
7. Photograph the completed pattern and any misplacements.

## Success criteria

- Object remains secure during movement.
- Release is predictable.
- Placement error is within the workshop tolerance.
- Failure modes are documented.
