# Experiment: Sensor-Assisted Fabrication

## Aim

Explore how sensor readings can inform setup verification, process monitoring, or simple feedback decisions.

## Suitable for

Intermediate workshops using approved sensors such as distance sensors, force sensors, cameras, or temperature probes.

## Variables

| Variable | Example |
| --- | --- |
| Sensor threshold | Distance, force, temperature, brightness |
| Sampling interval | Slow, baseline, fast |
| Response action | Pause, log, alert, adjust speed |
| Mounting position | Near tool, fixed frame, observation point |

## Procedure

1. Define the process question the sensor should answer.
2. Confirm that sensor wiring and mounting do not create motion hazards.
3. Record baseline readings with the robot stationary.
4. Run a slow dry motion and record readings.
5. Run a controlled fabrication or setup test.
6. Compare sensor data with visual observation.
7. Decide whether the sensor adds useful evidence.

## Documentation prompts

- What did the sensor detect well?
- What did the sensor miss?
- Did readings change with lighting, vibration, material, or tool angle?
- Would this sensor be used for monitoring, control, or documentation only?

## Safety notes

Do not rely on experimental sensing as a safety system unless it has been designed, certified, and approved for that purpose.
