# Experiment: Extrusion Path Calibration

## Aim

Determine a usable relationship between robot travel speed, extrusion flow, path spacing, and bead quality.

## Suitable for

Robotic clay, polymer, paste, or food-safe extrusion demonstrations where the material and tooling have already been approved by the lab.

## Variables

| Variable | Suggested range |
| --- | --- |
| Travel speed | Low, medium, high |
| Flow rate | Low, medium, high |
| Path spacing | 50-100 percent of bead width |
| Layer height | 50-90 percent of bead height |

## Constants

- Nozzle diameter
- Material batch
- Tool orientation
- Ambient conditions
- Build surface

## Procedure

1. Inspect tooling and material before loading.
2. Prime the extrusion system using the approved procedure.
3. Run a dry path with process output disabled.
4. Fabricate a straight-line test at baseline settings.
5. Change one variable at a time.
6. Photograph each trial from top and side views.
7. Record bead width, height, continuity, and visible defects.

## Success criteria

- Continuous bead
- No unsafe material buildup
- Predictable start and stop behavior
- Documented settings for the next test

## Safety notes

Confirm pressure limits, pinch points, temperature hazards, and cleanup procedure before running the test.
