# Curriculum Overview

## Audience

This curriculum is intended for learners who are new to robotic fabrication or are transitioning from CAD/CAM, CNC, architecture, product design, manufacturing, or maker education into robot-assisted workflows.

## Learning goals

By the end of the sequence, learners should be able to:

- Explain the relationship between digital models, toolpaths, end effectors, materials, and robot motion.
- Identify hazards in a robotic fabrication cell and follow safe operating procedures.
- Prepare a basic fabrication workflow from design intent to documented outcome.
- Run structured material and motion experiments.
- Record process variables, results, failures, and next-step recommendations.
- Present workshop outcomes using a concise summary format.

## Delivery formats

| Format | Duration | Best for | Notes |
| --- | ---: | --- | --- |
| Intro demo | 60-90 minutes | Visitors, open house, stakeholder previews | Use one low-risk demonstration and a short safety briefing. |
| Half-day workshop | 3-4 hours | First exposure for students or professionals | Use modules 1-2 plus one experiment. |
| Full-day workshop | 6-8 hours | Applied training | Use modules 1-4 plus documentation review. |
| Short course | 3-6 sessions | Deeper curriculum integration | Use all modules and a capstone. |
| Lab onboarding | Variable | New lab users | Emphasize safety, supervision, and approved workflows. |

## Module sequence

| Module | Title | Core outcome |
| --- | --- | --- |
| 01 | Introduction to Digital Fabrication | Learners can describe the robotic fabrication workflow. |
| 02 | Design for Robotic Fabrication | Learners can translate design intent into fabrication constraints. |
| 03 | Robot Programming Basics | Learners can read and reason about robot motion instructions. |
| 04 | End Effector and Toolpath Planning | Learners can connect tooling behavior to toolpath strategy. |
| 05 | Material Experimentation | Learners can run controlled tests and document variables. |
| 06 | Capstone Workshop | Learners can plan, fabricate, document, and critique a small project. |

## Recommended documentation cadence

| Stage | Participant artifact | Facilitator artifact |
| --- | --- | --- |
| Before workshop | Pre-reading notes, safety acknowledgement | Workshop brief, risk assessment |
| During setup | Setup photos, material notes | Setup checklist, inspection log |
| During experiment | Variables, observations, failures | Timing notes, safety observations |
| During review | Reflection and next-step notes | Rubric scores, summary comments |
| After workshop | Final process summary | Workshop summary report |
