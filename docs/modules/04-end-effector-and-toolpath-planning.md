# Module 04: End Effector and Toolpath Planning

## Purpose

Connect tool behavior to toolpath strategy so participants understand why fabrication planning changes with every end effector.

## Duration

90-150 minutes

## Learning outcomes

Participants will be able to:

- Identify how tooling affects motion, speed, material response, and safety.
- Describe toolpath parameters for additive, subtractive, forming, cutting, or assembly workflows.
- Plan a low-risk test path.
- Record end-effector assumptions in an experiment log.

## Common end-effector variables

| Tool type | Variables to document |
| --- | --- |
| Extrusion | Nozzle size, flow rate, temperature, layer height, speed |
| Milling | Tool diameter, spindle speed, feed rate, step-over, stock material |
| Hot wire | Wire temperature, travel speed, foam density, lead-in distance |
| Gripper | Payload, grip force, object tolerance, release position |
| Drawing or marking | Tip type, pressure, surface texture, speed |

## Activity

Participants select one tool type and prepare a test path with:

- Approach and retract moves
- Process start and stop points
- Speed assumptions
- Material placement
- Failure modes
- Documentation plan

## Deliverable

A toolpath planning sheet that can be reviewed before simulation or machine setup.
