# Module 06: Capstone Workshop

## Purpose

Guide participants through a small integrated project that includes design framing, safety review, toolpath planning, fabrication testing, documentation, and critique.

## Duration

One full day or 2-3 shorter sessions

## Learning outcomes

Participants will be able to:

- Propose a feasible robotic fabrication outcome.
- Prepare a workshop brief and risk notes.
- Run at least one documented fabrication test.
- Present results, limitations, and next-step recommendations.

## Required artifacts

- Project brief
- Risk assessment
- Toolpath or motion plan
- Experiment log
- Process photos
- Final workshop summary

## Suggested structure

| Phase | Activity | Output |
| --- | --- | --- |
| Frame | Define project intent and constraints | Brief |
| Plan | Select tool, material, and path strategy | Planning sheet |
| Check | Review safety, setup, and dry-run procedure | Checklist |
| Test | Run small trial | Experiment log |
| Iterate | Adjust one variable | Comparison notes |
| Present | Share process, result, and recommendation | Summary |

## Review questions

- What did the process prove?
- What remains uncertain?
- Which variable should be changed next?
- What safety or setup change would improve the next session?
