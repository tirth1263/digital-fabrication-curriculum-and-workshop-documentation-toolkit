# Module 05: Material Experimentation

## Purpose

Teach participants how to run small, controlled fabrication tests before scaling a robotic process.

## Duration

2-3 hours

## Learning outcomes

Participants will be able to:

- Define a testable material question.
- Select variables and constants.
- Record results with units, photos, and observations.
- Use evidence to recommend the next test.

## Experiment structure

| Step | Action |
| --- | --- |
| 1 | State the material question. |
| 2 | Identify the variable to change. |
| 3 | Hold other variables constant. |
| 4 | Run a small test. |
| 5 | Record measurements and photos. |
| 6 | Review failure or success criteria. |
| 7 | Recommend the next test. |

## Example variables

- Tool speed
- Layer height
- Temperature
- Material moisture
- Path spacing
- Tool angle
- Fixturing pressure
- Cooling time

## Deliverable

A completed experiment outline using `docs/templates/experiment-outline-template.md`.
