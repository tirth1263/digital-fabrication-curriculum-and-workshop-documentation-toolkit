# Module 02: Design for Robotic Fabrication

## Purpose

Help participants translate design ideas into constraints that can be evaluated through robotic fabrication.

## Duration

90-120 minutes

## Learning outcomes

Participants will be able to:

- Identify fabrication constraints in a digital design.
- Distinguish geometric intent from toolpath feasibility.
- Prepare a design for material and motion testing.
- Document assumptions before fabrication.

## Required materials

- CAD model, sketch, or parametric study
- Fabrication constraint worksheet
- Sample material dimensions
- Access to relevant software or exported screenshots

## Key concepts

- Reachability
- Tool orientation
- Work envelope
- Fixturing
- Material tolerance
- Sequencing
- Collision avoidance

## Exercise

Participants choose a simple geometry and complete a constraint review:

| Question | Notes |
| --- | --- |
| What is the design intent? |  |
| What material is assumed? |  |
| What tool contacts or transforms the material? |  |
| What movement is required? |  |
| What could collide, shift, burn, melt, crack, or fail? |  |
| What must be tested first? |  |

## Deliverable

A one-page design-for-fabrication note with annotated screenshots or sketches.
